# FUORISEDE — Roadmap MVP Ferrara

## Priorità immediata
Obiettivo: web app funzionante e rapidamente testabile nel periodo caldo della ricerca alloggi.

### MVP
- [x] Repository GitHub operativo
- [x] Prima home responsive
- [x] Ricerca centrata su università/polo
- [x] Card sintetiche
- [x] Anteprima mappa
- [x] Dataset dimostrativo Ferrara
- [x] Preferiti persistenti nel browser
- [ ] Collegare filtri UI al dataset
- [ ] Scheda completa dell'alloggio
- [ ] Comparatore alloggi
- [ ] Candidatura e numero candidati
- [ ] Alert nuovi annunci
- [ ] Mappa reale e servizi circostanti

## Acquisizione offerta
Non dipendere da un solo portale. Normalizzare annunci provenienti da fonti diverse, nel rispetto delle condizioni d'uso e delle autorizzazioni disponibili.

Fonti da verificare/attivare:
- portali immobiliari;
- agenzie/intermediari;
- proprietari;
- gruppi e post social, con particolare attenzione alla verifica e alla qualità del dato;
- studentati e residenze.

## Differenziazione
FUORISEDE non deve essere un altro elenco di annunci. Il nucleo del prodotto è: università → sede/polo → posizione → alloggio → costo reale → affidabilità → recensioni/esperienze, con comparazione e candidatura.

## Lancio
Ferrara è il banco di prova. Prima del lancio pubblico: sostituire tutti i dati dimostrativi con fonti autorizzate/verificate, testare il flusso con studenti reali e definire le regole anti-frode.
